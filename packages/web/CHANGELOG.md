# Changelog

## 0.1.0 (2026-06-07)

### Features

- Initial release
- Real-time temperature dashboard with 10-second auto-refresh
- Alarm color coding (red for high, blue for low)
- Expandable temperature history charts per device
- Light/dark theme toggle with system preference detection
- Public share viewer for devices and archives (no auth required)
- Responsive mobile-first layout
