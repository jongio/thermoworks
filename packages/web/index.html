🔥 ThermoWorks
Tools

CLI, SDK, VS Code extension, and integrations for your ThermoWorks Cloud connected thermometers. Check temps from the terminal, VS Code status bar, or build automations with live readings. 

npx thermoworks

Not affiliated with, endorsed by, or connected to ThermoWorks. Built by ThermoWorks customers, for ThermoWorks customers.

What you can do

Features

🚨

Temperature alerts

Instant visual alarms — red when too high, blue when too low. VS Code blinks the status bar to grab your attention.

📋

VS Code device panel

Full sidebar tree view with all devices, live channel readings, battery levels, and firmware — right in your editor.

📟

Copilot CLI statusline

Live temperatures appear in the GitHub Copilot CLI footer while you code. Pick devices and channels with an interactive wizard.

💻

VS Code status bar

Temperatures in the VS Code footer at a glance. Auto-refreshes and shares credentials with the CLI.

📊

Per-channel selection

Pick averages or individual channels for multi-probe devices like the Signals 4-channel.

🛠️

SDK for custom integrations

Build your own dashboards, alerts, or automations with the thermoworks-sdk Node.js package.

🔐

Secure credential storage

Credentials stored in the OS keychain (macOS Keychain, Windows Credential Vault, libsecret). Sign in once — CLI and VS Code share access.

⚡

Fast & lightweight

Zero install with npx. Smart caching keeps API calls low. Built on undici connection pooling.

Get started

Quick Start

1

Sign in

npx thermoworks auth login
2

List your devices

npx thermoworks devices
3

Set up Copilot statusline

npx thermoworks copilot setup

Integration

Copilot CLI Statusline

Run the setup wizard to pick devices and channels. Temps appear in the Copilot CLI footer while you work.

Integration

VS Code Extension

Install the ThermoWorks extension from the VS Code Marketplace to see live temperatures in the status bar and a full device panel in the sidebar. Shares credentials and device config with the CLI — sign in once and both tools work.

1

Install the extension

Search "ThermoWorks" in the VS Code Extensions panel, or install from the Marketplace.

2

Sign in

Use the ThermoWorks: Login command, or the CLI shares credentials automatically.

3

See temperatures

Temps appear in the status bar: 🔥 Smoker:225°F · Meat:145°F. Hover for details.

Stay informed

Temperature Alerts

When a channel's alarm triggers, both the CLI and VS Code immediately show visual alerts — red for too high, blue for too low. VS Code also blinks the status bar to grab your attention.

🔴 High Alarm

Temperature exceeded the high threshold

🔵 Low Alarm

Temperature dropped below the low threshold
