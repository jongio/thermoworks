Unofficial community tool

ThermoWorks CLI

Live temperature readings from your ThermoWorks devices in the GitHub Copilot CLI statusline

Not affiliated with ThermoWorks. An unofficial community tool.

Get started

Quick Start

npx thermoworks auth login
npx thermoworks copilot setup

Why use it

Features

  • 🔥 Live temps in Copilot CLI statusline
  • 🔐 OS keychain credential storage
  • 📊 Per-device, per-channel selection
  • ⚡ Configurable refresh rate with caching
